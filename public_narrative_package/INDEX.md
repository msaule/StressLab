# Public Narrative Package Index

This folder contains the curated public figure set for StressLab's first research narrative.

## What Is Here

- `figures/main_result.png`: best single summary figure for README, portfolio, and talks
- `figures/collapse_overlay.png`: cross-domain collapse probability versus utilization
- `figures/phase_transition.png`: topology-level threshold curves
- `figures/fragility_heatmap.png`: utilization-coupling collapse region map
- `figures/early_warning.png`: shared early-warning behavior
- `figures/feature_laws.png`: leading predictors and interpretable law candidates
- `figures/healthcare_case.png`: baseline-collapse-intervention case study graphic
- `figures/controlled_thresholds.png`: controlled follow-up collapse curves
- `figures/threshold_shift.png`: coupling-driven threshold shift
- `figures/failure_margin.png`: coupling-driven shock margin compression
- `figures/healthcare_validation.png`: healthcare threshold validation
- `figures/followup_main_result.png`: follow-up summary figure

## How To Use It

- Use `main_result.png` as the default lead visual.
- Use `collapse_overlay.png` and `threshold_shift.png` together to explain the core claim.
- Use `healthcare_case.png` when telling the story to a non-research audience.
